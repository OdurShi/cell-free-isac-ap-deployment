# Data

The paper uses no external dataset. Its training data are produced by the simulation
environment: the positions of the three UEs, drawn around fixed centres, and the sample
points of the target's circular trajectory (Section 4 of the paper). This directory holds
that data as files, generated once with fixed seeds by
[`scripts/generate_data.py`](../scripts/generate_data.py), so that the training and
evaluation sets are fixed and can be inspected. The archived training artefacts of the
original experiments are in [`experiments/`](../experiments).

## How the data are produced

* **UE positions.** One snapshot holds the positions of the K = 3 UEs. Each UE is drawn from
  a Gaussian around its centre, (25, 45), (10, 15) and (40, 10) m, with variance 2 per
  coordinate ("three UEs distributed around the target follow Gaussian distributions with a
  variance of 2", Section 4), using `numpy.random.default_rng(seed).normal` through
  `ScenarioConfig.sample_ues`; values are clipped to the observation range [-10, 60] m. The
  training split uses seed 1, the evaluation split seed 0.
* **Target trajectory.** `Q = 25` points `linspace(0, 2 pi, 25)` (both ends included) on a
  circle of radius 10 m; one file per configuration family.
* **Candidate sites and UE centres.** Written from the scenario configuration.

The scenario constants behind these files (region, grid, trajectory, UE centres) and where
they come from are listed in [`docs/implementation_notes.md`](../docs/implementation_notes.md).

## How the code uses the data

* The training environment takes, at every step, a block of 25 consecutive snapshots of the
  training split (one snapshot per trajectory point), chosen uniformly at random with the
  run's seed.
* Evaluation during training uses the evaluation split in the same way. The optimisers and
  the table scripts score deployments on the first `n` snapshots of the evaluation split.
* The directory is found at `data/` of a source checkout; `--data-dir` (for `cfisac train`)
  or the environment variable `CFISAC_DATA_DIR` select another location. If the files are
  absent, or a scenario changes the UE centres or variance, the same distribution is sampled
  on the fly; `cfisac train --online-ues` requests that explicitly.
* The trajectory, site and centre files mirror what the code computes from the scenario
  configuration; `tests/test_data.py` checks that they are identical.

## Regenerating and checking

```bash
python scripts/generate_data.py --out data          # rewrites the files and manifest.json
python -c "from cfisac.data import verify; print(verify())"
```
